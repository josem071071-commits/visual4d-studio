Política de Privacidad

Versión 1.0 · Responsable: Jose Guerrero / Visual 4D Studio · Estados Unidos

Documento preparado para publicación. Debe mantenerse alineado con la operación real del servicio y revisarse cuando cambien proveedores, funciones o requisitos regulatorios.

1. Alcance

Esta política describe cómo Visual 4D Studio trata información cuando una persona utiliza la aplicación, sus herramientas MCP o experiencias integradas en plataformas de terceros. El servicio ayuda a crear, estructurar, verificar y producir piezas visuales mediante el Método Visual 4D.

2. Datos que puede procesar

Según la función utilizada, el servicio puede recibir contenido que el usuario decida enviar, instrucciones y parámetros de trabajo, identificadores técnicos para autenticación y aislamiento de proyectos, recursos visuales proporcionados expresamente y datos operativos mínimos necesarios para seguridad, diagnóstico y prevención de abuso. Se aplica minimización de datos: no se debe solicitar información personal innecesaria para la función pedida.

3. Finalidades

Los datos se procesan para ejecutar funciones solicitadas, mantener proyectos y versiones cuando corresponda, autenticar y autorizar usuarios, preservar trazabilidad y aprobaciones explícitas, proteger el servicio, diagnosticar fallos y cumplir obligaciones legales aplicables.

4. Contenido del usuario

El usuario conserva los derechos que le correspondan sobre los archivos y contenidos que aporte. Visual 4D Studio no reclama propiedad sobre ellos por el mero hecho de procesarlos. Los recursos designados como maestros deben preservarse conforme a las reglas del flujo.

5. Entrenamiento

Visual 4D Studio no utilizará por iniciativa propia contenido privado del usuario para entrenar modelos de propósito general. El tratamiento realizado por plataformas o proveedores independientes se rige por sus propios términos y configuraciones.

6. Proveedores

El servicio puede utilizar proveedores de infraestructura estrictamente necesarios para alojamiento, base de datos, observabilidad o integración. Visual 4D Studio no vende datos personales.

7. Conservación

Los datos se conservarán únicamente durante el tiempo razonablemente necesario para prestar el servicio, mantener seguridad e integridad, resolver disputas y cumplir obligaciones legales.

8. Seguridad

Se utilizan controles de autenticación, separación entre usuarios y proyectos, autorización por operación, HTTPS, límites operativos y aprobación explícita para acciones sensibles. Ningún sistema puede garantizar seguridad absoluta.

9. Derechos y solicitudes

Cuando resulte aplicable, una persona podrá solicitar acceso, corrección o eliminación de sus datos y ejercer otros derechos reconocidos por la legislación correspondiente.

10. Menores

Visual 4D Studio no está diseñado para recopilar intencionalmente datos personales de menores sin la autorización o base legal requerida.

11. Transferencias internacionales

Los proveedores tecnológicos pueden procesar información en distintos países. Cuando resulte exigible, se aplicarán mecanismos adecuados para proteger las transferencias internacionales.

12. Cambios

Esta política podrá actualizarse cuando cambien las funciones, proveedores o requisitos regulatorios. La versión vigente se mostrará en esta página.
