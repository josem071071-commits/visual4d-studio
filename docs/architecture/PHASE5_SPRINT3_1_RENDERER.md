# Visual 4D — Phase 5 / Sprint 3.1 RenderSpec + Reference Renderer

## Objective
Convert an approved deterministic `LayoutSpec` into a versioned, testable `RenderSpec` and produce the first reproducible visual artifact generated by Visual 4D Studio.

## Scope

- Add `packages/renderer` with a dependency-free SVG reference renderer.
- Define `visual4d.render.v1` as the first render contract.
- Convert headline/body/footer/hero placeholder content into positioned render elements.
- Reject invalid layouts before rendering.
- Validate unique element IDs and canvas bounds.
- Escape user-controlled text before SVG output.
- Generate an exact 1080×1920 SVG from the deterministic layout solver.
- Produce a CI reference artifact at `certification/samples/sprint3_1_reference.svg`.

## Non-goals

- No raster image decoding or embedding yet.
- No external font loading.
- No AI image generation.
- No free-form browser editor.
- No production deployment.

## Closure gates

Sprint 3.1 is closed only when CI proves:

1. core build and full typecheck remain green;
2. Sprint 2 certification suites remain green;
3. Sprint 3 layout tests remain green;
4. Sprint 3.1 RenderSpec/renderer tests pass;
5. the reference SVG is generated successfully;
6. PostgreSQL/MCP certification remains green.
