# Política de Privacidad — Visual 4D Studio

**Versión:** 1.0 — borrador de publicación  
**Fecha:** 29 de agosto de 2026  
**Responsable:** José Guerrero / Visual 4D Studio

## 1. Alcance
Esta política describe cómo Visual 4D Studio trata información cuando una persona utiliza la aplicación, sus herramientas MCP o sus experiencias integradas en ChatGPT. Visual 4D Studio es una plataforma de asistencia para crear, estructurar, verificar y producir piezas visuales mediante el Método Visual 4D.

## 2. Datos que puede procesar la aplicación
Según la función utilizada, Visual 4D Studio puede recibir: contenido que el usuario decide enviar a la aplicación; instrucciones, textos y parámetros necesarios para producir o verificar una pieza; identificadores técnicos necesarios para autenticar al usuario y aislar sus proyectos; recursos visuales que el usuario proporcione expresamente; y datos operativos mínimos necesarios para seguridad, diagnóstico, prevención de abuso y funcionamiento del servicio.

Visual 4D Studio debe aplicar minimización de datos: no solicitar información personal que no sea necesaria para la función pedida por el usuario.

## 3. Finalidades
Los datos se procesan únicamente para: ejecutar las funciones solicitadas; mantener proyectos y versiones cuando la función lo requiera; autenticar y autorizar usuarios; preservar trazabilidad y aprobaciones explícitas; proteger el servicio; diagnosticar fallos; y cumplir obligaciones legales aplicables.

## 4. Contenido del usuario y recursos maestros
El usuario conserva los derechos que le correspondan sobre el contenido y archivos que aporte. Los recursos identificados como archivos maestros deben preservarse conforme a las reglas del producto y no deben ser reinterpretados generativamente cuando la política del flujo los proteja.

Visual 4D Studio no reclama propiedad sobre el contenido del usuario por el mero hecho de procesarlo.

## 5. Uso para entrenamiento
Visual 4D Studio no utilizará por iniciativa propia el contenido privado del usuario para entrenar modelos de propósito general. El tratamiento que realicen plataformas o proveedores independientes se rige por sus propios términos y configuraciones.

## 6. Compartición y proveedores
La aplicación puede utilizar proveedores de infraestructura estrictamente necesarios para operar el servicio, por ejemplo alojamiento, base de datos, observabilidad o servicios de plataforma. Solo deben recibir la información necesaria para prestar su función y estarán sujetos a sus respectivos compromisos contractuales y de seguridad.

Visual 4D Studio no vende datos personales.

## 7. Conservación
Los datos se conservarán únicamente durante el tiempo razonablemente necesario para proporcionar el servicio, mantener la integridad y seguridad del sistema, resolver disputas y cumplir obligaciones legales. Antes de la publicación general se documentarán los plazos concretos de conservación por categoría de datos.

## 8. Seguridad
Visual 4D Studio utiliza controles diseñados para reducir acceso no autorizado, incluyendo autenticación, separación entre usuarios/proyectos, autorización de operaciones, HTTPS, límites operativos y controles explícitos para acciones sensibles. Ningún sistema puede garantizar seguridad absoluta.

## 9. Derechos y solicitudes
Cuando resulte aplicable, una persona podrá solicitar acceso, corrección o eliminación de sus datos personales y ejercer otros derechos reconocidos por la legislación correspondiente. Antes del lanzamiento público se publicará un canal de privacidad verificable para estas solicitudes.

## 10. Menores
Visual 4D Studio no está diseñado para recopilar intencionalmente datos personales de menores de edad sin la autorización o base legal requerida.

## 11. Transferencias internacionales
Los proveedores tecnológicos pueden procesar información en distintos países. Cuando resulte exigible, se aplicarán mecanismos adecuados para proteger las transferencias internacionales.

## 12. Cambios
Esta política podrá actualizarse cuando cambien las funciones, proveedores o requisitos regulatorios. La fecha y versión vigentes se mostrarán en esta página.
